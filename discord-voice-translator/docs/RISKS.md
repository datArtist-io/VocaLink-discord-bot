# Risk register (status as of 5 Oct 2026)

| # | Risk | Severity | Status / evidence | Mitigation built |
|---|---|---|---|---|
| R1 | **DAVE receive.** Discord began requiring end-to-end-encrypted voice (DAVE) for bot voice connections in March 2026 (libraries without DAVE fail with close code 4017). | **High** | `@discordjs/voice` 0.19.0 implemented DAVE; 0.19.1 always installs `@snazzah/davey`; 0.19.2 (13 Mar 2026) is the latest release. **Open upstream issues:** discord.js #11419 (decrypt failures / reconnect loops, partially addressed) and **#11441 (~34 % of packets silently dropped around MLS key transitions — open)**. Maintainers describe receive as "it may work". py-cord cannot receive DAVE audio at all; discord.py needs an unofficial fork. So the TS edge is still the best option, but **receive must be proven on your server**. | `daveEncryption: true`, `decryptionFailureTolerance: 36`; davey pinned to ≥ 0.1.12 (Jun 2026 "libdave parity" fixes); receive streams auto-resubscribe after an error; packet-gap + error health monitor **rejoins** the channel (fresh MLS group) when receive degrades; edge fills lost time with silence so STT timing stays correct; **Phase 0 spike** (`npm run dave-spike`) measures loss overall and around join/leave transitions and writes per-user WAVs. **Blocker if the spike fails** — see TESTING.md. |
| R2 | **Model licences.** | High | NLLB-200, MMS (TTS/ASR) and SeamlessM4T are **CC-BY-NC 4.0**. Piper's engine (piper1-gpl) is **GPL-3.0**; voices have individual licences. MIT/Apache: Whisper/faster-whisper, Silero, CTranslate2, MADLAD-400, Chatterbox. | `COMMERCIAL=true` drops every non-commercial provider and switches MT to MADLAD-400 (Apache-2.0). Then Yoruba/Hausa/Igbo lose MMS voices → captions-only unless a commercial cloud voice key is set. Run Piper as a separate process (it is) and review GPL obligations before redistributing the worker image. See LICENSES.md. |
| R3 | **Nigerian languages are weak locally.** | High | Whisper large-v3 WER is high for Yoruba and Hausa (tone marks often dropped); Igbo and Pidgin are not Whisper languages. | Honest tiering + reasons in `/languages`; `/mylang speak:` override; Pidgin detection on transcripts; MMS-1b Igbo ASR add-on; hybrid mode lets a cloud key take only these languages. Needs your test clips to quantify (`bench.py --clips`). |
| R4 | **Voice cloning abuse / biometric law.** Voiceprints are biometric data (e.g. Illinois BIPA, GDPR Art. 9). | High | — | Self-enrollment only, inside the call, with a **live random read-aloud phrase verified by STT** (≥ 55 % similarity) — uploads impossible; explicit consent screen naming purpose, storage, labelling and deletion; consent version recorded; profiles **AES-256-GCM encrypted**, filenames are keyed hashes; `/voice delete` overwrites + unlinks immediately; admins must also enable `voice: clone`; dubs in cloned voice are marked 🗣️; Chatterbox adds an inaudible watermark. **Get legal review before offering cloning to the public.** |
| R5 | **Discord policy flags in this design.** | Medium | (a) Mirror channels need extra bot accounts: allowed only as **separate, disclosed bot applications you own**, never user accounts (self-bots break the ToS); don't use them to evade per-bot limits on servers you don't administer. (b) Developer Policy §21: no training ML/AI models on content obtained via the API without Discord's permission — this bot never trains on user data. (c) You need a published **privacy policy** describing voice processing (Developer Terms). (d) Summaries and analytics are personal data → retention + deletion. | Join notice in the channel every session; `/optout` (edge drops audio before decoding); no audio stored; transcript kept in RAM only until the summary; analytics contain no text; caption index (for `/correct`) 24 h; analytics 30 days; PRIVACY_URL shown in the notice. See POLICY.md. |
| R6 | **GPU load from "streaming" Whisper.** Re-decoding the growing buffer multiplies GPU work per speaker. | Medium | — | Partials are shed whenever a final decode is waiting or all STT workers are busy (finals always have priority); per-tier speaker capacity; queue/shed counters on the dashboard. |
| R7 | **Per-listener audio.** One bot output per channel; an Activity cannot mute other users' original audio for a listener. | Medium | — | Captions → mirror channels → web companion (built in that order); instructions to lower User Volume. |
| R8 | **Cross-talk and stale dubs.** | Medium | — | One dub at a time per output, ducking, barge-in cut, stale drop (3 s), max 3 waiting; worker cancels TTS for dubs nobody will play. |
| R9 | **Language-ID flip-flop / code-switching.** | Medium | — | Per-speaker smoothing with confusable groups, sustained-evidence switching, periodic re-check, pause-based split for long utterances, `expected_langs` server setting. |
| R10 | **LLM-only features without an LLM** (natural/cultural modes, Pidgin output, abstractive summary). | Medium | — | Literal NMT always works; natural/cultural fall back with a visible note; summaries fall back to a labelled extractive summary; one Ollama container enables all of it locally. |
| R11 | **Reconnects, rate limits, sharding.** | Low | — | Voice: Signalling/Connecting grace then rejoin with backoff; captions: token bucket (≈ 5 msgs / 5 s per channel), debounced edits, digest messages under load; sharding via `ShardingManager` (per-shard web port). |
| R12 | **Untested integration surface.** This build environment could not install npm/PyPI packages or download models. | **High** | See TESTING.md: everything except the Discord transport and real model inference is covered by 71 automated tests; the Discord layer was compiled against stubs and reviewed, and the model glue was tested against stand-in modules. Neither was **executed for real**. | Phase 0 checklist: install, `npm run typecheck`, `npm test`, `python -m unittest`, `dave-spike`, `bench.py`. |
| R13 | **Cost (only if you add keys).** | Low | Local mode costs only the server. | Each provider declares cost/hour; `policy.max_cloud_usd_per_hour` reserved for a budget guard; hybrid mode limits cloud to weak languages. |
